# 99 Templates & Examples

Reusable templates and examples for workflow creation.

## Template Categories

### by-technology/
Technology-specific workflow templates and patterns:
- **mqtt/**: MQTT subscriber and publisher examples
- **rest-api/**: REST API CRUD operations
- **websocket/**: Real-time data workflows
- **grpc/**: gRPC client integration

### by-pattern/
Design pattern templates:
- **etl/**: Extract, Transform, Load workflows
- **event-driven/**: Event-based processing
- **batch-processing/**: Batch job templates

### Other Templates
- **lead-gen/**: Lead generation workflow variations

## Usage

1. **Select Template**: Choose the template that matches your use case
2. **Customize**: Modify variables, credentials, and business logic
3. **Deploy**: Deploy to your n8n instance
4. **Test**: Validate the workflow with test data

## Best Practices

- Always test in a development environment first
- Replace placeholder credentials with your own
- Follow naming conventions: kebab-case
- Document any customizations made
- Add descriptive comments for complex logic

## Contributing

When creating new templates:
1. Use descriptive names
2. Include comprehensive README
3. Use consistent structure
4. Test thoroughly before submission
